# Kaya Portfolio Website

현대적이고 반응형 포트폴리오 웹사이트입니다.

## 기능

- **반응형 디자인**: 모든 디바이스에서 완벽하게 작동
- **모던 UI**: 깔끔하고 전문적인 디자인
- **부드러운 애니메이션**: 스크롤 애니메이션 및 호버 효과
- **연락처 폼**: 방문자가 직접 메시지를 보낼 수 있는 기능
- **프로젝트 쇼케이스**: 포트폴리오 프로젝트 전시

## 프로젝트 구조

```
Kaya_website/
├── index.html          # 메인 HTML 파일
├── css/
│   └── style.css       # 스타일시트
├── js/
│   └── script.js       # JavaScript 기능들
├── images/             # 이미지 폴더
│   ├── profile.jpg     # 프로필 사진 (추가 필요)
│   ├── project1.jpg    # 프로젝트 1 이미지 (추가 필요)
│   ├── project2.jpg    # 프로젝트 2 이미지 (추가 필요)
│   └── project3.jpg    # 프로젝트 3 이미지 (추가 필요)
└── README.md           # 프로젝트 설명서
```

## 설치 및 실행

1. 프로젝트를 클론하거나 다운로드합니다.
2. `images` 폴더에 필요한 이미지들을 추가합니다:
   - `profile.jpg`: 프로필 사진
   - `project1.jpg`, `project2.jpg`, `project3.jpg`: 프로젝트 이미지들
3. `index.html` 파일을 웹 브라우저에서 열거나 라이브 서버를 사용합니다.

## 커스터마이징

### 개인 정보 수정
`index.html` 파일에서 다음 정보들을 수정하세요:
- 이름 및 직책
- 소개글
- 연락처 정보
- 소셜 미디어 링크

### 프로젝트 정보 수정
프로젝트 섹션에서 본인의 실제 프로젝트로 교체하세요:
- 프로젝트 제목
- 설명
- 사용 기술
- 링크

### 스킬 수정
스킬 섹션에서 본인의 기술 스택으로 변경하세요:
- 기술 이름
- 숙련도 퍼센트

### 색상 테마 변경
`css/style.css` 파일에서 CSS 변수나 색상 값들을 수정하여 원하는 색상으로 변경할 수 있습니다.

## 사용된 기술

- **HTML5**: 시맨틱 마크업
- **CSS3**: 플렉스박스, 그리드, 애니메이션
- **JavaScript**: DOM 조작, 이벤트 처리, 스크롤 애니메이션
- **Font Awesome**: 아이콘
- **Google Fonts**: Poppins 폰트
